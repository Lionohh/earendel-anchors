# earendel-anchors

에렌델(Earendel)이 운영하는 봉인 원장의 **외부 시점확인 기록** 공개 저장소입니다.

> **중요 안내**
>
> **IDAQA-DA/01은 에렌델이 공개·운영하는 자체 검증 규칙입니다.** ISO·국가표준 또는 공인 인증 체계가 아니며, 에렌델은 제3자 인증기관이 아닙니다.
>
> 이 저장소에서 확인할 수 있는 범위는 RFC 3161 시점 토큰의 해시값과 공개된 봉인 대상 요약 문서의 일치 여부, 그리고 현재 공개 문서의 변경 여부입니다. 기록 내용의 진실성, 농산물의 품질·등급·안전성, 센서 교정 상태 또는 기록과 실물의 동일성을 인증하거나 보증하지 않습니다.

## 공개 자료와 확인 범위

에렌델은 생육·수확 기록에서 산출한 원장 요약값을 회차별 봉인 대상 문서에 기록하고, 해당 문서의 SHA-256 해시값에 대해 RFC 3161 시점 토큰을 발급받습니다.

공개 회차와 시각은 [INDEX.csv](INDEX.csv)를 기준으로 확인하십시오. 누구나 에렌델의 서버나 계정 없이 다음 항목을 직접 대조할 수 있습니다.

* 시점 토큰의 전자서명이 함께 공개된 TSA 인증서 체인으로 검증되는지
* 토큰의 해시값이 공개된 봉인 대상 문서의 해시값과 일치하는지
* 회차별 `chain_digest`와 `rows`의 변화가 서로 부합하는지

명령 예시는 [VERIFY.md](VERIFY.md)에 있습니다. 결과는 위의 확인 범위 안에서 해석해야 합니다.

## 구성

| 경로                            | 내용                            |
| ----------------------------- | ----------------------------- |
| `anchors/anchor_YYYYMMDD.txt` | 봉인 대상 요약 문서(원장 요약값 포함)        |
| `anchors/anchor_YYYYMMDD.tsq` | RFC 3161 시점확인 요청 파일           |
| `anchors/anchor_YYYYMMDD.tsr` | RFC 3161 시점 토큰                |
| `certs/tsa.crt`               | TSA 공개키 인증서                   |
| `certs/cacert.pem`            | 검증에 사용하는 인증서 체인               |
| `INDEX.csv`                   | 공개 회차별 요약                     |
| `IDAQA-DA-01_v1.0.html`       | IDAQA-DA/01 v1.0 역사 문서(원본 보존) |
| `SHA256SUMS`                  | 보존 대상 파일의 SHA-256 목록          |

## 봉인 대상 문서의 `ip_snapshots`

`ip_snapshots`에는 에렌델이 보관 중인 지식재산 관련 자료 묶음의 파일명과 해시값이 들어 있습니다.

나중에 제시된 파일이 당시 봉인 대상의 해시값과 일치하는지 대조하기 위한 정보이며, 자료의 내용·권리관계·유효성 자체를 확인하지 않습니다. 원본 자료도 이 저장소에 공개하지 않습니다.

## 역사 문서 보존

`IDAQA-DA-01_v1.0.html`은 최초 공개 당시의 원본입니다. `SHA256SUMS`에 해시가 기록되어 있고 시점확인 대상에 포함되었으므로 덮어쓰지 않습니다.

파일 내부의 과거 명칭은 ISO·국가표준 또는 공인 인증을 의미하지 않습니다. 이후 정정은 새 버전과 변경 이력으로 관리합니다.

## 이 저장소에 없는 것

원본 데이터, 소스코드, 검증 절차의 내부 구현, 개인정보와 거래 정보는 포함하지 않습니다.

## 이용

누구나 파일을 내려받아 공개 기록의 시점과 변경 여부를 대조하는 목적으로 사용할 수 있습니다.
