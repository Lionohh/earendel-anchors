# earendel-anchors

에렌델(Earendel)이 운영하는 봉인 원장의 **외부 시점확인 기록** 공개 저장소입니다.

## 이 저장소는 무엇인가

에렌델은 농산물의 생육·수확 데이터를 사후 수정이 불가능한 형태로 봉인하고,
원장 전체의 요약값을 주 1회 외부 시각인증기관(RFC 3161)에 제출하여 시점 토큰을 발급받습니다.

이 저장소에는 **그 토큰과 봉인 대상 문서 전부**가 들어 있습니다.
따라서 누구나 **에렌델의 협조 없이** 다음을 확인할 수 있습니다.

- 특정 시점에 원장이 어떤 상태였는지
- 그 이후 원장이 소급 수정되지 않았는지
- 토큰이 실제로 발급기관의 서명을 받았는지

검증 방법은 [VERIFY.md](VERIFY.md)에 있습니다. 표준 도구(OpenSSL) 외에 필요한 것은 없습니다.
계정을 만들거나 권한을 요청할 필요가 없습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `anchors/anchor_YYYYMMDD.txt` | 봉인 대상 문서 (원장 요약값 포함) |
| `anchors/anchor_YYYYMMDD.tsq` | 시점확인 요청 파일 |
| `anchors/anchor_YYYYMMDD.tsr` | 발급된 시점 토큰 |
| `certs/tsa.crt` | 발급기관 인증서 |
| `certs/cacert.pem` | 루트 인증서 |
| `INDEX.csv` | 회차별 요약 (토큰에서 직접 파싱한 값) |
| `SHA256SUMS` | 전 파일 무결성 목록 |

## 봉인 대상 문서에 포함된 것

각 `.txt`에는 원장 요약값과 함께 `ip_snapshots` 항목이 있습니다.
이는 에렌델이 보관 중인 지식재산 관련 자료 묶음의 **파일명과 해시값**으로,
해당 자료가 그 시점에 이미 존재했음을 함께 증명하기 위해 봉인 대상에 포함한 것입니다.
**자료 자체는 이 저장소에 공개하지 않습니다.**

## 이 저장소에 없는 것

원본 데이터, 소스코드, 검증 절차의 내부 구현은 포함하지 않습니다.
공개되는 것은 **요약값과 그 요약값에 대한 외부 기관의 서명**뿐이며,
개인정보나 거래 정보는 포함되지 않습니다.

## 이용

이 저장소의 파일은 누구나 자유롭게 내려받아 검증 목적으로 사용할 수 있습니다.
